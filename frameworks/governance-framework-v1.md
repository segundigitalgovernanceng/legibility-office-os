# Executive Summary

Governance is often described as leadership, policymaking, or administration.

Within the Institutional Operating System (IOS), governance is something more fundamental.

Governance is the operating logic through which institutions make decisions, allocate authority, coordinate action, manage risk, preserve legitimacy, and continuously improve.

This framework positions governance as the foundation upon which procurement, public finance, Digital Public Infrastructure (DPI), institutional memory, coordination, and national capability are built.

Rather than treating governance as a single institution, IOS treats governance as the system that enables all institutions to function coherently.

---

# Definition

**Governance** is the structured system through which public institutions exercise authority, make decisions, coordinate resources, manage accountability, and generate long-term public value.

Governance determines how institutions behave.

---

# Core Principle

> Governance is not an institution.

> Governance is the operating system through which institutions become capable.
