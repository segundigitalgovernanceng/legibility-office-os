# Legibility Office Institutional Operating System (IOS)

## Project Roadmap

**Vision**

Build the world's leading open-source reference architecture for institutional capability, governance, procurement, Digital Public Infrastructure (DPI), and AI-enabled public systems.

This repository is designed to evolve into a global knowledge commons for governments, development finance institutions, researchers, policymakers, and practitioners.
