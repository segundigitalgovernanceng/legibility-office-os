# Institutional Capability Framework

## Capability as the Strategic Outcome of the Institutional Operating System

**Version:** 0.1

**Project:** Legibility Office Institutional Operating System (IOS)

---

# Executive Summary

The fundamental purpose of institutions is not to exist.

It is to produce capability.

Many governments possess ministries, agencies, regulations, budgets, and policies.

Yet institutional presence is not institutional capability.

Capability is demonstrated only when institutions consistently transform resources into public outcomes.

Within the Institutional Operating System (IOS), **institutional capability is the cumulative ability of governance systems to coordinate, execute, learn, adapt, and continuously improve over time.**

Capability is therefore not a resource.

It is an emergent property of institutional architecture.

---

# Definition

**Institutional Capability** is the sustained ability of public institutions to design, coordinate, execute, learn from, and continuously improve the delivery of public value under changing conditions.

Capability transforms institutional inputs into national outcomes.

---

# Core Principle

> Institutions do not become capable because they possess more resources.

> They become capable because their operating systems continuously improve how resources are converted into outcomes.

# Long-Term Vision

This Institutional Capability Framework provides an open reference architecture for governments, development finance institutions, regulators, public agencies, researchers, and practitioners seeking to strengthen state capability through institutional design rather than isolated reform.
