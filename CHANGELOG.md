# Versioning Policy

Major versions introduce significant architectural or conceptual changes.

Minor versions introduce new frameworks, documentation, or capabilities while maintaining compatibility.

Patch versions include:

* Documentation improvements
* Editorial corrections
* Diagram updates
* Schema refinements
* Minor enhancements

---

# Long-Term Vision

The Legibility Office Institutional Operating System is intended to become an open reference architecture for governments, development finance institutions, researchers, practitioners, and technology organizations seeking to strengthen institutional capability.

This changelog documents the evolution of that mission over time.
