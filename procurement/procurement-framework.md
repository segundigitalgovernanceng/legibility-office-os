# Legibility Office Procurement Capability Framework (PCF)

## Version

1.0

---

# Purpose

The Procurement Capability Framework (PCF) defines procurement as a strategic institutional capability rather than an administrative purchasing function.

Within the Institutional Operating System (IOS), procurement is the principal mechanism through which governments transform public finance into productive national capability.

The framework shifts procurement away from compliance toward institutional value creation.

---

# Core Principle

Procurement allocates capability.

Every procurement decision shapes future institutional capacity.
